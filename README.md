
# Application de gestion de bibliothèque

## Description

Application console développée en Python permettant de gérer
une collection de livres.

Les données sont sauvegardées dans un fichier JSON pour
être conservées entre les lancements de l'application.

## Fonctionnalités

- Ajouter un livre
- Afficher tous les livres
- Rechercher un livre par titre ou auteur
- Supprimer un livre par identifiant
- Sauvegarder et charger les données en JSON
- Vérifier les saisies utilisateur

## Technologies utilisées

- Python
- JSON
- Git
- GitHub

## Prérequis

- Python 3 installé
- Git installé

## Installation et lancement

1. Cloner le dépôt GitHub.
2. Ouvrir un terminal dans le dossier du projet.
3. Lancer la commande :

   python main.py

## Structure du projet

- main.py : code de l'application
- bibliotheque.json : données de la bibliothèque

## Compétences travaillées

- Variables et conditions
- Boucles et fonctions
- Listes et dictionnaires
- Lecture et écriture de fichiers JSON
- Gestion des erreurs
- Versionnement avec Git
